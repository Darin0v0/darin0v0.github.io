features

CodeMirror Editor

Profesjonalny edytor z kolorowaniem składni C++, numeracją linii, automatycznym wcięciem i indywidualnymi ustawieniami

Monitoring aktywności

Zbudowane na nowoczesnym stacku Node.js

  • Node.js Serwer i środowisko uruchomieniowe
  • Express Framework webowy
  • Socket.IO Komunikacja real-time
  • CodeMirror Edytor kodu
  • JSON Baza danych
server.js
const express = require('express');
const http = require('http');
const { Server } = require("socket.io");

const app = express();
const server = http.createServer(app);
const io = new Server(server);

io.on('connection', (socket) => {
    socket.on('code-change', (data) => {
        io.emit('code-update', data);
    });
});

server.listen(3000);
